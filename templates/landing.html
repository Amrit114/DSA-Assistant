How does binary search work?

Binary search

Compare the target with the middle element and discard the half that can't contain it. Each step halves the range, giving O(log n) time.

while lo <= hi:
mid = (lo + hi) // 2
if a[mid] == x: return mid
if a[mid] < x: lo = mid + 1 # go right
else: hi = mid - 1
